1 · Settings

Used by both tools below. Set the group once (for example the sir's name) and every paper you add gets it.

2 · Create many papers at once

One title per line. A 4-digit year in the title is picked up automatically.

3 · Upload whole folders

Creates the papers and uploads every question image in one go. Arrange your folders like this, then choose the top folder:

All papers/
  Sunil Sir/          ← group
    Paper 01/         ← paper
      001.png … 050.png
    Paper 02/
  Nimal Sir/
    Paper 01/

No sir folders? Use All papers/Paper 01/001.png and the group from Settings is used. Papers with the same name in the same group are added to, not duplicated, and existing answer keys are kept.
